# Janob IELTS — AI‑экзаменатор IELTS Speaking

Веб‑приложение для подготовки к IELTS Speaking. Пользователь выбирает экзаменатора (голос),
проходит устный экзамен в реальном времени — Part 1, Part 2 (карточка + минута подготовки),
Part 3 — и получает оценку по четырём критериям IELTS, разбор ошибок и план подготовки.

Экзаменатор говорит по‑английски. Если кандидат отвечает на узбекском (или русском),
экзаменатор коротко отвечает **на том же языке голосом** («Iltimos, ingliz tilida javob bering…»)
и возвращается к вопросу на английском. Интерфейс — на узбекском и английском.

## Как это устроено

```
Браузер ──WebSocket (эфемерный токен)──► Gemini Live  gemini-3.8-live
   │  микрофон 16 kHz PCM ► / ◄ голос экзаменатора 24 kHz + субтитры
   │
   ├─ POST /api/live/token  → системный промпт экзаменатора, голос, инструменты; токен на 1 сессию
   ├─ POST /api/evaluate    → gemini-3.5-transcribe (распознавание EN/UZ)
   │                          → gemini-3.8-flash (оценка по аудио + транскрипту, JSON)
   └─ GET/POST /api/tts     → gemini-3.1-flash-tts-preview (прослушивание голосов и образцовых ответов)
```

| Задача | Модель Google | Где |
|---|---|---|
| Живой диалог с экзаменатором (speech‑to‑speech, EN + UZ) | `gemini-3.8-live` | браузер, Live API |
| Распознавание речи кандидата (code‑switching EN/UZ, дословно) | `gemini-3.5-transcribe` | `/api/evaluate` |
| Оценка по критериям IELTS, ошибки, план | `gemini-3.8-flash` (thinking: high) | `/api/evaluate` |
| Озвучка превью голосов и ответов Band 8–9 | `gemini-3.1-flash-tts-preview` | `/api/tts` |

Любую модель можно заменить переменной окружения (см. `.env.example`).

Ключевые решения:

- **API‑ключ не попадает в браузер.** Сервер выдаёт эфемерный токен, в котором зафиксированы модель,
  промпт, голос, инструменты и настройки звука (явной маской полей: SDK сам строит неверную маску).
  Браузер может добавить только handle для восстановления сессии — подменить промпт нельзя.
- **Структура экзамена управляется инструментами модели:** `set_exam_part` (прогресс),
  `start_preparation_time` (карточка + таймер 1 минуты, микрофон выключается), `end_exam`.
  Модель часто сначала вызывает инструмент и ждёт ответа: если она ещё не говорила в этом ходе,
  ответ отправляется с `WHEN_IDLE` (продолжай), иначе — `SILENT` (без повтора реплики).
- **Полудуплекс:** пока экзаменатор говорит, микрофон не отправляется — экзаменатор не перебивает
  сам себя эхом из колонок. Паузы до 1,1 с не обрывают ответ кандидата.
- **Точная оценка произношения:** записываются только ответы кандидата (Opus ~32 kbps) и отправляются
  в оценщик вместе с транскриптом. Балл = среднее четырёх критериев, округлённое вниз до 0,5.
- Сессии Live API длиннее 10 минут переподключаются автоматически (session resumption + сжатие контекста).
- История тестов хранится в `localStorage` браузера (без регистрации).

## Запуск

1. Получите ключ Gemini API: <https://aistudio.google.com/apikey>
2. Создайте `.env.local`:

   ```bash
   cp .env.example .env.local
   ```

   и впишите `GEMINI_API_KEY=...`
3. Установите зависимости и запустите:

   ```bash
   npm install
   ```

   ```bash
   npm run dev
   ```

4. Откройте <http://localhost:3000> в Chrome, Edge или Safari, разрешите микрофон.
   Лучше в наушниках.

Микрофон работает только на `localhost` или по HTTPS.

### Превью голосов

Кнопка прослушивания у экзаменаторов проигрывает готовые файлы из `public/voices/*.mp3`
(8 голосов × 3 акцента), поэтому звучит мгновенно. Если поменяете голоса или текст превью
в `src/app/api/tts/route.ts`, перегенерируйте их (нужны запущенный `npm run dev` и `ffmpeg`):

```bash
npx tsx scripts/generate-voice-previews.ts
```

Без этих файлов превью синтезируется на лету через `/api/tts`.

## Деплой (Vercel)

Добавьте `GEMINI_API_KEY` в Environment Variables проекта и задеплойте. `/api/evaluate` использует
`maxDuration = 300` секунд; запись ответов укладывается в лимит тела запроса Vercel (4,5 МБ).

## Стоимость

Ориентировочно $0.15–0.30 за полный тест (Live API ≈ $0.005/мин входящего и $0.018/мин исходящего
аудио, плюс распознавание и оценка). Бесплатный уровень Gemini API подходит для разработки.

## Перед публичным запуском

- Добавьте авторизацию (например, Telegram Login или NextAuth) перед `/api/live/token`,
  `/api/evaluate` и `/api/tts`: сейчас есть только проверка origin и простой лимит запросов по IP.
- Перенесите историю в базу данных, если нужна синхронизация между устройствами.

## Структура

```
src/app/api/live/token   эфемерный токен + конфигурация экзаменатора
src/app/api/evaluate     распознавание + оценка
src/app/api/tts          синтез речи
src/lib/server/          промпты экзаменатора и оценщика, клиент Gemini
src/lib/live/            движок экзамена в браузере: Live‑сессия, микрофон, воспроизведение, запись
src/lib/exam/            темы Part 1–3, план теста, подсчёт балла, типы
src/components/          интерфейс: боковая панель, выбор экзаменатора, экзамен, результаты
public/worklets/         AudioWorklet для захвата микрофона (16 kHz PCM)
public/voices/           готовые превью голосов (MP3)
scripts/                 генерация превью голосов
```
